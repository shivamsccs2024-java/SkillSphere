# SkillSphere – Learning & Career Development Platform

**Learn. Grow. Achieve.**

SkillSphere is a responsive learning and career development platform built using React. It helps students explore courses, track their learning progress, and follow structured career roadmaps.

## Features

- **Home Page:** Explore popular categories, featured courses, and student testimonials.
- **Courses:** Search, filter, and sort available courses.
- **Course Details:** View course descriptions, curriculum, and enrollment options.
- **Student Dashboard:** Track enrolled courses and learning progress.
- **Career Roadmap:** Follow learning paths and mark completed steps.
- **My Profile:** View and update profile information.
- **Contact & Support:** Submit messages through a contact form.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **LocalStorage:** Saves demo user data, enrollments, progress, and messages.

## Technologies Used

- React.js
- JavaScript
- Bootstrap 5
- CSS3
- React Router DOM
- Lucide React
- Vite
- Browser LocalStorage

## Installation & Setup

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd skillsphere
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
